## Projects 

### SPDC Photon-Pair source (Final-Year Project, Distinction) 
Designed and built an optical system from scratch to generate photon pairs via spontaneous parametric down-conversion.

- **Experimental:** ultrafast Ti:Sapphire laser, second harmonic generation (810 nm to 405 nm) to pump SPDC, spectral filtering, and single-photon detection with SPADs and time-correlated single photon counting (TCSPC)
- **Simulation (Python):** BBO refractive index dispersion, SHG and SPDC phase matching angles, group velocity mismatch, entanglement time, and joint spectral intensity
- **Analysis:** verified quadratic SHG power scaling, measured a zero-delay coincidence peak, and tracked coincidence rate stability over time
- **Tools:** Python, NumPy, SciPy, Matplotlib
